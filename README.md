## 🎞️ Про проєкт

**Cinema Team** — це консольна програма для роботи з інформацією про фільми та кінотеатр.

Програма дозволяє користувачу взаємодіяти з даними через консольне меню та виконувати основні операції з фільмами, акторами й квитками.

## 💻 Вимоги

Перед запуском переконайтеся, що на комп'ютері встановлено:

* Windows 10 або Windows 11
* Visual Studio 2022 або новіша версія
* компонент **Desktop development with C++**
* Git

### Встановлення Git

Завантажити Git можна з офіційного сайту:

https://git-scm.com/

Після встановлення відкрийте **Git Bash**.

Перевірити встановлення Git:

```bash
git --version
```

Якщо команда виконана успішно, ви побачите встановлену версію Git.

# 📥 Клонування проєкту

Відкрийте **Git Bash** та перейдіть у папку, де хочете зберегти проєкт.

Наприклад:

```bash
cd ~/Desktop
```

Після цього клонуйте репозиторій:

```bash
git clone https://github.com/nikilodiym/cinemaTeam.git
```

Перейдіть у папку проєкту:

```bash
cd cinemaTeam
```

Перевірити файли проєкту можна командою:

```bash
ls
```

# 🚀 Запуск проєкту

## 1. Відкрити проєкт

У папці `cinemaTeam` знаходиться файл:

```text
cinemaTeam.sln
```

Відкрийте його за допомогою **Visual Studio**.

---

## 2. Встановити компоненти C++

Якщо Visual Studio ще не налаштована для C++, відкрийте:

**Visual Studio Installer → Modify**

та встановіть:

```text
Desktop development with C++
```

Після встановлення перезапустіть Visual Studio.

---

## 3. Зібрати проєкт

У Visual Studio відкрийте:

```text
Build → Build Solution
```

або використайте:

```text
Ctrl + Shift + B
```

Якщо збірка пройшла успішно, можна запускати програму.

---

## 4. Запустити програму

Для запуску без режиму налагодження використовуйте:

```text
Ctrl + F5
```

Або:

```text
Debug → Start Without Debugging
```

# 📁 Структура проєкту

```text
cinemaTeam/
│
├── cinemaTeam.sln
├── cinemaTeam.vcxproj
│
├── main.cpp
│
├── domain.h
├── movie.h
├── interface_actor.h
├── header_lib.h
│
├── movie_management.h
├── movie_management.cpp
│
├── search.h
├── search.cpp
│
├── ticket_booking.h
└── ticket_booking.cpp
```

### Основні файли

| Файл                   | Призначення               |
| ---------------------- | ------------------------- |
| `main.cpp`             | Точка входу в програму    |
| `movie.h`              | Робота з фільмами         |
| `movie_management.cpp` | Керування фільмами        |
| `search.cpp`           | Пошук                     |
| `ticket_booking.cpp`   | Бронювання квитків        |
| `interface_actor.h`    | Робота з акторами         |
| `domain.h`             | Основні структури та дані |
